## Project Description
This lab project implements a registration form that:
- Collects user details (First/Last Name, Email, Programme, Year, Interests, Photo URL).
- Validates inputs with inline error messages and accessibility support.
- Dynamically generates a profile card for each registration.
- Maintains a synchronized summary table of all profiles.
- Allows removing profiles (both from the card and the table).

### Stretch Goals (Implemented)
- Edit feature: Update an existing profile.
- LocalStorage: Save and reload profiles even after refreshing the page.
- Search/Filter: Search profiles by name or programme.
